# NIRVAN – Context-Aware Audio Language Model (ALM)

🚀 **Smart India Hackathon 2025 Project**  
**Problem Statement ID:** 25242  
**Theme:** Smart Automation  
**Category:** Software  

NIRVAN is a **Deep Learning–based Audio Language Model (ALM)** that can **listen, think, and understand both speech and non-speech audio together** to infer real-world situations.

---

## 📌 Problem Statement

Traditional speech recognition systems focus only on **spoken words** and ignore **environmental sounds** like alarms, footsteps, sirens, machinery noise, etc.  
This limits contextual understanding in real-world scenarios such as **airports, smart cities, defense zones, and surveillance systems**.

---

## 💡 Proposed Solution

NIRVAN introduces a **Context-Aware Audio Intelligence System** that:

- 🎙️ Understands **speech content**
- 🔊 Detects **non-speech environmental sounds**
- 🧠 Performs **scene-level reasoning**
- 🌐 Supports **multilingual audio**
- 📊 Displays insights via an **interactive dashboard**

The model fuses audio signals and language understanding to answer:  
> *“What is happening in this environment?”*

---

## 🏗️ System Architecture

**Core Modules:**
- Automatic Speech Recognition (ASR)
- Audio Event Detection (AED)
- Audio–Language Fusion Engine
- Transformer-based Reasoning Engine
- Web Dashboard for visualization
